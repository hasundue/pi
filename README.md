# pi

Personal configuration and skills for [pi](https://github.com/earendil-works/pi) — the coding agent harness.

## Structure

- `.pi/` — agent configuration, schedules, and settings
- `SKILL.md` — custom skills (if any)
- `AGENTS.md` — agent-level instructions

## Usage

This repo is checked out by pi to `~/pi` and loaded automatically on startup.
